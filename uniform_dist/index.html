連続一様分布 $U(a, b)$

連続一様分布 $U(a, b)$ は、区間 $[a, b]$ において、どの値も同じ確率密度で現れる分布です。

  • 確率密度関数 (PDF): $f(x) = \frac{1}{b-a}$ （$a \le x \le b$ のとき）

パラメータ $a$ と $b$ を変更すると、青色で描かれた確率密度関数の幅と高さが変化します。
「1回生成」または「自動生成」を実行すると、選ばれた実数が赤いヒストグラムとして積み上がり、試行回数を重ねるにつれて理論値（青い枠）の形に近づいていくことを確認しましょう。
